# Relatório: Troca de IP da FastAPI para 192.168.10.14

## 1. Alteração Solicitada
Troca do IP `127.0.0.1` para o IP da interface de rede local `192.168.10.14`.

## 2. Ações Executadas
1. **Configuração da FastAPI (`fastapi_service/config.py`):**
   - `API_HOST` alterado de `127.0.0.1` para `192.168.10.14`.
   - Validação com `python3 -m py_compile fastapi_service/config.py` (sucesso).
2. **Script de Inicialização (`fastapi_service/start.sh`):**
   - `export API_HOST="${API_HOST:-192.168.10.14}"`.
3. **Reinicio do Serviço:**
   - Processo anterior encerrado.
   - FastAPI iniciada e vinculada à interface `192.168.10.14:8800`.
4. **Atualização da Documentação:**
   - `API_DOCUMENTATION.md` e `contexto/13-guia-seguranca-e-api.md` atualizados com todos os comandos e links apontando para `http://192.168.10.14:8800`.
5. **Testes de Conectividade:**
   - `curl -s http://192.168.10.14:8800/healthz` -> `{"status":"ok"}`.
   - `curl -s http://192.168.10.14:8800/api/posts` -> 200 OK com lista de posts.
